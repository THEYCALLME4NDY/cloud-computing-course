# Cloud Computing Concepts Reflection

Cloud computing has become an important part of my daily life because many of the applications I use rely on cloud services. Three cloud services that I regularly use are Google Drive, Facebook Messenger, and Canva.

Google Drive is an example of **Software as a Service (SaaS)** because it allows users to store, manage, and share files through a web browser without installing complex software. It uses the **Public Cloud** deployment model since it is available to anyone with a Google account and is hosted by Google.

Facebook Messenger is also a **Software as a Service (SaaS)** application. It provides instant messaging, voice calls, and video calls through the internet. Messenger is hosted on Meta's public cloud infrastructure, making it another example of the **Public Cloud** deployment model.

Canva is another **Software as a Service (SaaS)** platform because users can create presentations, posters, and other graphic designs entirely online without managing servers or software installations. Since Canva is accessible to anyone through the internet, it is also classified under the **Public Cloud** deployment model.

Version control is very important in cloud computing because cloud projects often involve many developers working on the same files. Without version control, changes could easily be overwritten or lost. Git and GitHub allow developers to track every modification, review previous versions, and restore files when mistakes happen. GitHub also supports collaboration through branches and pull requests, making it easier for teams to develop cloud applications safely and efficiently. By using version control, teams can work together, reduce errors, and maintain a complete history of their projects.

Overall, this activity helped me understand that cloud computing is already part of my everyday life. It also showed me how GitHub plays an essential role in organizing projects, collaborating with others, and maintaining reliable cloud-based systems. I believe these skills will be valuable as I continue studying information technology and eventually work in the IT industry.
